## Welcome to Amulet

Amulet is an open-source Minecraft world editor and format converter. It lets you browse, edit and convert Java and Bedrock edition saves.

- **3D Editor** — modify the world directly in a 3D view.
- **Convert** — convert worlds between platforms/versions.

> This is a community-maintained documentation mirror. Source code and releases are on
> the [GitHub repository](https://github.com/YHXJLB/Amulet-Map-Editor).
