# 世界转换器教程

转换前你需要准备：

- Amulet
- 想要转换的世界（称为 `source world`，源世界）
- 一个与目标 Minecraft 平台 / 版本相同的世界（称为 `destination world`，目标世界）

## 转换步骤

1. 将 `source world`（源世界）载入 Amulet
2. 世界载入完成后，启动 `Convert`（转换）子程序

![Convert 子程序位于世界界面左侧](/images/world_screen_converter.png)

3. 点击 `Select Output World`（选择输出世界）按钮，按相同的载入流程选择你想要的 `destination world`（目标世界）
4. 目标世界载入完成后，点击 `Convert`（转换）按钮
5. 进度条会随转换进度更新，到达末尾时会弹出如下对话框：

![转换完成](/images/conversion_finished.png)

6. 转换完成后，关闭 Amulet，并在目标 / 所需 Minecraft 版本 / 平台中打开 `destination world`（目标世界）即可。
