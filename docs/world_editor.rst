世界编辑器教程
=====================

3D 编辑器（``3D Editor``）是 Amulet 的核心子程序，
您可以在其中浏览并编辑整个 Minecraft 世界。

进入编辑器
----------------

按照 :ref:`opening-a-world-ref` 打开世界后，
点击左侧的 ``3D Editor`` 标签页即可进入 3D 编辑器界面。

视角控制
----------------

* **鼠标左键**：操作当前选中的工具（如选择、放置方块等）
* **鼠标右键拖动**：旋转视角
* **鼠标滚轮**：缩放视野
* **W / A / S / D**：平移视角
* **Space / Shift**：上升 / 下降

基本操作流程
----------------

1. 在工具栏中选择 ``Select``（选择）工具
2. 在世界中点击并拖动，框选您要操作的区域
3. 选区完成后，可使用 ``Edit``（编辑）菜单中的操作：
   * ``Copy``（复制）—— 复制选区内容
   * ``Paste``（粘贴）—— 粘贴已复制的内容
   * ``Delete``（删除）—— 删除选区内的方块
   * ``Fill``（填充）—— 用指定方块填充选区
4. 误操作时可使用 ``Undo``（撤销）/ ``Redo``（重做）

保存修改
----------------

编辑完成后，点击 ``Save``（保存）按钮将修改写回世界文件。
:emphasis:`注意：保存操作会直接修改世界文件，建议提前备份。`

.. note::
    3D 编辑器仍在持续开发中，不同版本之间的界面和快捷键可能存在差异。
