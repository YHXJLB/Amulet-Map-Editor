世界转换器教程
========================

您需要准备：

* Amulet
* 需要转换的世界（下称 ``源世界``）
* 一个与目标 Minecraft 平台和版本相同的世界（下称 ``目标世界``）

1. 将 ``源世界`` 加载到 Amulet 中
2. 世界加载完成后，启动 ``Convert``（转换）子程序

.. figure:: _static/images/world_screen_converter.png
    :scale: 75 %
    :align: center

    ``Convert`` 子程序位于世界界面的左侧

3. 点击 ``Select Output World``（选择输出世界）按钮，
   按照与打开世界相同的流程选择您的 ``目标世界``
4. ``目标世界`` 加载完成后，点击 ``Convert``（转换）按钮
5. 进度条将显示转换进度，转换完成后会弹出如下对话框：

.. figure:: _static/images/conversion_finished.png
    :scale: 75 %
    :align: center

6. 转换完成后，您可以关闭 Amulet，
   并在目标 Minecraft 版本/平台中打开 ``目标世界``
